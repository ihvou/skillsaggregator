Copy everything between the rules below into ChatGPT (use its deep research / web-browsing mode).
It is written to be self-contained — no context from this repo is needed.

The point of running it is **independent triangulation**: a second pass that did not see my probe
results, so where it agrees the list is solid, and where it disagrees is worth checking.

## What counts as a good sub-skill

**1. It is a real rung on a real teaching progression.** Ground your suggestions in an actual
curriculum — a governing-body syllabus, a coaching certification content list, an established
teaching progression — and name the source. For these seven, the relevant bodies are roughly: R&A/USGA
Rules and the PGA teaching model (golf); ITTF coaching progression (table tennis); indoor-climbing
instructor awards and the BMC rope-skills sequence (climbing); USA Pickleball rules and PPR coaching
order (pickleball); PSIA/BASI Level 1–2 alpine progression (skiing); AASI/BASI snowboard progression
(snowboarding); the standard white-to-blue-belt, position-before-submission syllabus (BJJ). Use
better sources if you know them.

**2. The name is a retrieval key, not a label.** My collector builds YouTube search queries directly
from the sub-skill name. A name nobody puts in a video title retrieves the wrong content. Real
examples of this failing:

- A page named "Starting to run" collected generic running content and published 2 of 16 candidates.
  Renamed to "Couch to 5K", it started collecting the right thing immediately.
- "Wedge christie" is exactly correct PSIA terminology for the rung between wedge and parallel
  turns — and it is unusable, because the best video titled that way has about 3,000 views. Nobody
  titles a video "wedge christie".
- "Around the head shot" (badminton) retrieved almost nothing; the phrase people actually use is
  "round the head".

So: no parentheticals, no internal jargon, no coach-speak. If a technique has a niche name and a
common name, give both and tell me which one people actually search.

**3. Dedicated single-topic tutorials must exist for it.** This is the hard gate and the one that
kills most candidates. I need videos that teach ONE thing. I do not want:

- follow-along classes or workout routines ("20 MIN CORE WORKOUT", "Mat Pilates for Back Pain")
- guided sessions ("10-Minute Guided Loving Kindness Meditation")
- highlight compilations, match footage, vlogs, gear reviews, or "top 10 craziest points" videos

This is not hypothetical. I had to reject a whole meditation category on this basis — every sub-skill
I tested returned guided sessions rather than instruction. Within these seven categories it also
killed "pickleball drop shot" (identical videos to "third shot drop"), "open hand grip" in climbing,
and "snowboard skating and gliding".

**4. It does not overlap something I already have.** Before suggesting anything, check whether the
same videos would serve an existing page. If they would, say so and do not suggest it.

## Method I want you to follow

For each of the seven categories:

1. Find the curriculum a real learner would follow. Name the source.
2. Compare it against my list above.
3. Report what is genuinely missing — and **say plainly when a category is already complete**. I
   would much rather read "Golf is well covered, 2 real gaps" than get a padded list of twelve
   marginal ideas. I expect several of these categories to need very little.

## For each missing sub-skill, give me

- **Name**, phrased the way a tutorial would title it (see rule 2 above)
- **Priority**: MUST-HAVE (a learner would notice its absence) / SHOULD-HAVE / NICE-TO-HAVE
- **Why it is standard** — one line, tied to the curriculum source you named
- **Tutorial availability**: HIGH / MEDIUM / LOW, judged strictly on whether DEDICATED single-topic
  tutorials exist. **Cite 2–3 real video titles as evidence**, with approximate view counts. Mark LOW
  honestly — a page I cannot fill is worse than no page.
- **Overlap check**: does it meaningfully differ from what I already have, or would the same videos
  serve both pages?

## Also tell me

- Any of my **existing** sub-skill names that look wrong for search, redundant with another, or
  too broad or too narrow versus how the discipline is actually taught.
- Anything where you are **unsure** — flag it rather than padding.

## One important verification rule

If a YouTube search returns titles in a language you did not expect, **do not conclude the query is
off-idiom.** YouTube serves auto-translated title metadata; the underlying videos are frequently
English-language videos from exactly the right channels. Check the channel name before drawing any
conclusion about a name. I got this wrong once and nearly renamed a page that was working fine.

## Output format

Group by category, MUST-HAVE first. Put a one-line verdict at the top of each category
("well covered — 2 gaps" / "significant gaps — 7 missing"). Be concise; evidence matters more than
prose.
